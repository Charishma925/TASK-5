# Decision Trees and Random Forests on Iris Dataset

## Objective
Learn how to apply **Decision Tree** and **Random Forest** models for classification using the **Iris dataset**. This task also involves:
- Visualizing trees,
- Analyzing overfitting and controlling model complexity,
- Comparing model performance,
- Interpreting feature importances,
- Evaluating using cross-validation.

---

## Tools & Libraries Used
- Python
- Scikit-learn
- Graphviz (for visualizing decision trees)
- Matplotlib / Seaborn (for plotting)
- NumPy, Pandas

---

## Dataset
We use the **Iris dataset**, a classic multi-class classification problem that includes:
- **150 samples**
- **3 target classes** (Setosa, Versicolor, Virginica)
- **4 features**:
  - sepal length
  - sepal width
  - petal length
  - petal width

Loaded directly using `sklearn.datasets.load_iris()`.

---

## Steps to perform the task

### 1. Load and Explore Data
- Load dataset using Scikit-learn
- Check class distribution and feature statistics

### 2. Train a Decision Tree Classifier
- Train using `DecisionTreeClassifier`
- Visualize tree using `Graphviz`
- Evaluate accuracy on test data

### 3. Visualize & Control Overfitting
- Compare results with varying `max_depth` to demonstrate overfitting vs. generalization
- Use `train_test_split` to check performance across splits

### 4. Train a Random Forest Classifier
- Use `RandomForestClassifier`
- Compare accuracy with Decision Tree

### 5. Interpret Feature Importances
- Use `.feature_importances_` from Random Forest
- Plot importance scores

### 6. Evaluate with Cross-Validation
- Use `cross_val_score` for k-fold CV (e.g., `cv=5`)
- Report mean accuracy and standard deviation
